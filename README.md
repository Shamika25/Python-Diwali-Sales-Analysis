# Python Diwali Sales Analysis

This project performs Exploratory Data Analysis (EDA) on Diwali sales data to uncover key consumer behaviors, purchasing patterns, and sales trends. The goal is to provide data-driven insights that can help a retail business improve customer targeting and increase revenue.

## 📊 Project Overview
* *Objective:* Analyze customer demographics (age, gender, location, profession) to identify top-performing segments.
* *Dataset:* Includes variables such as User ID, Product Category, State, Zone, Occupation, Age Group, Gender, Amount, and Orders.
* *Technology Stack:* Python, Jupyter Notebook.

## 🚀 Key Features & Insights
* *Gender Analysis:* Evaluates purchasing power and order frequency between male and female buyers.
* *Age Demographics:* Identifies which age bracket contributes most to total sales revenue.
* *Geographic Distribution:* Highlights the top-performing states and zones.
* *Product Insights:* Reveals the most popular product categories during the festival.

## 🛠️ Required Python Libraries
To run this project locally, you need the following libraries installed:
* numpy
* pandas
* matplotlib
* seaborn
